## Conventions

- **Slug** = source-card filename (kebab-case, no `.md`).
- **Type** = paper / preprint / dataset doc / model card / course material / standard / blog post / etc.
- **Level** = EBSE evidence level (L1 official docs · L2 peer-reviewed · L3 standards/RFCs · L4 codebase · L5 verified community).
- **Status** = `stub | draft | stable` from the source card's frontmatter.
- **Cited by** = wiki pages currently citing this card. Maintained on ingest (per [`CLAUDE.md` §7](../../CLAUDE.md)).

## How to add a row

When ingesting a new source (per [`CLAUDE.md` §7](../../CLAUDE.md) step 5): create the source card, then append one row above. Keep the table sorted by ingest order (oldest first). Append `EDIT` to [`log.md`](../../log.md).
