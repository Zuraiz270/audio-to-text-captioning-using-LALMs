## Description

The official course assignment definition for the Computational Humanities Master's project. 

- **Definition:** "Moving beyond simple classification, sound event captioning describes complex acoustic scenes in natural language."
- **Method:** "This project utilizes state-of-the-art Large Audio-Language Models (LALMs) to 'write' descriptions of audio clips."

## Target Datasets

- **Clotho** or **AudioCaps** (identified as "typical for these models").

## Primary Research Question

**"How accurately can LALMs describe overlapping sound events compared to traditional tagging?"**

This establishes **RQ2 (Polyphony Under-Description)** as the central academic requirement for the course output, elevating it above general captioning benchmarks.

## Relevance to Project

This document represents the absolute ground-truth for project grading and scope bounding. Any work done in this wiki must ultimately serve to answer the primary research question defined in these slides.
